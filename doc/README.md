## Provenance and caveats

- **The PDK itself carries no PDF documentation.** sky130A has no `libs.doc/` folder, unlike the IHP PDKs, so this folder links the online documentation instead of copying it. The version this template was measured against is in [sky130A-Open-PDK/README.md](sky130A-Open-PDK/README.md): open_pdks `026824c7969ce6f4fc9678e6ca04b0a06a596c4b`, the PDK of the IIC-OSIC-TOOLS 2026.08 image.
- **Numbers here come from the installed PDK, not from a datasheet.** The metal stack table in the LibreLane cheatsheet is read out of `sky130_fd_sc_hd__nom.tlef`, the PCell list out of `libs.tech/klayout/python/cells/`, the corner sections out of `libs.tech/ngspice/sky130.lib.spice`. Re-read them after a PDK update, the commands are in each document.
- **Nothing in `doc/` is generated by a make target.** It is all hand-maintained, except the plot overviews in `sizing/`, which come from the techsweep data.
